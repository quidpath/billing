QUICK START
===========

Windows:
--------

   .\start-all-dev.bat

2. Test admin access:
   .\test-admin-access.bat

3. If issues, run diagnostics:
   .\check-dev-services.bat

Linux/Mac:
----------
chmod +x start-all-dev.sh
./start-all-dev.sh

WHAT IT DOES
============

1. Creates shared Docker network (quidpath_network)
2. Stops any existing containers
3. Builds and starts all services:
   - Backend (port 8000)
   - Billing (port 8002)
   - Tazama AI (port 8001)
4. Runs database migrations
5. Creates admin superusers

TROUBLESHOOTING
===============

Admin Panel Not Loading:
------------------------
1. Check service is running: docker ps
2. Check logs: docker logs django-backend-dev
3. Verify migrations: docker exec django-backend-dev python manage.py showmigrations
4. Create superuser: docker exec -it django-backend-dev python manage.py createsuperuser

Port Already in Use:
--------------------
1. Stop existing containers: docker compose -f docker-compose.dev.yml down
2. Check what's using port: netstat -ano | findstr :8000
3. Kill process or change port in docker-compose.dev.yml

Database Connection Error:
--------------------------
1. Check database is running: docker ps | grep postgres
2. Wait a few seconds for database to initialize
3. Restart service: docker compose -f docker-compose.dev.yml restart

Cannot Access Admin:
--------------------
1. Verify superuser exists:
   docker exec django-backend-dev python manage.py shell -c "from django.contrib.auth import get_user_model; print(get_user_model().objects.filter(username='admin').exists())"

2. Create superuser if needed:
   docker exec -it django-backend-dev python manage.py createsuperuser

3. Check ALLOWED_HOSTS in .env.dev includes localhost

USEFUL DOCKER COMMANDS
======================

List Running Containers:
docker ps

List All Containers:
docker ps -a

Stop All Containers:
docker stop $(docker ps -aq)

Remove All Containers:
docker rm $(docker ps -aq)

View Container Logs:
docker logs -f <container-name>

Execute Command in Container:
docker exec -it <container-name> bash

Rebuild Without Cache:
docker compose -f docker-compose.dev.yml build --no-cache

Clean Up Everything:
docker system prune -a

Common Issues:
- Port in use: Change port or stop conflicting service
- Database error: Wait for database to initialize
- Admin not accessible: Create superuser
- Code changes not reflecting: Check volume mount
