TROUBLESHOOTING:
----------------

If workflow fails:
[ ] Check Actions tab for error message
[ ] Verify secrets are correct (SERVER_HOST and SSH_PRIVATE_KEY)
[ ] Test SSH manually: ssh ubuntu@51.77.147.233
[ ] Check server: docker ps
[ ] Review logs: docker logs <container-name>

Common fixes:
- Wrong SSH key: Re-add SSH_PRIVATE_KEY secret
- Permission denied: sudo usermod -aG docker quidpath
- Git pull fails: Check repo is in ~/quidpath-deployment/
- Health check fails: Check service is running
