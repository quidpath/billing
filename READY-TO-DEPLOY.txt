DEPLOYMENT COMMANDS (MANUAL):
==============================

If you need to deploy manually (without GitHub Actions):

SSH to server:
ssh ubuntu@51.77.147.233
su - quidpath

Deploy all services:
cd ~/quidpath-deployment
./cleanup-and-deploy.sh

Deploy single service:
cd ~/quidpath-deployment/<service>
docker compose build --no-cache
docker compose up -d --no-deps --build <service-name>
docker exec <container-name> python manage.py migrate --noinput
docker exec <container-name> python manage.py collectstatic --noinput

Deployment fails:

2. Verify secrets are correct

5. Review logs: docker logs <container-name>

Common issues:

- Permission denied: Add quidpath to docker group
- Git pull fails: Check repo location
- Health check fails: Check service running
